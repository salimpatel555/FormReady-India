# FormReady India

Free, privacy-first online tools for Indian government exam applications (photo, signature, PDF, EMI).

## Highlights

- **11 tools** – photo/signature resize, compress, grayscale, PDF merge/convert, EMI calculator
- **21 Indian languages** with Noto fonts
- **Dark mode** with smooth transitions (desktop + mobile switch)
- **Client-side only** – files stay in the browser
- **Search & filter** on tools page
- **Toast notifications**, scroll-to-top, polished UI

## Quick start

```bash
npm install
npm run dev
```

## Stack

Next.js 15 · React 19 · Tailwind CSS 4 · TypeScript · pdfjs-dist · jspdf · pdf-lib

## Build

```bash
npm run build && npm start
```
